#  Simon Says Game

A simple **Simon Says** memory game built using **HTML, CSS, and JavaScript**.

##  How to Play

1. Press any key to start the game.
2. The game will show a sequence of colors.
3. Remember the sequence.
4. Click the colored buttons in the same order.
5. Each round adds one new color to the sequence.
6. If you click the wrong button, the game is over.
7. Try to remember as many sequences as possible and achieve a high score!

## Technologies Used

* HTML
* CSS
* JavaScript

## Features

* Interactive color buttons
* Increasing difficulty with each level
* Random color sequences
* Score/level tracking
* Game-over detection
* Simple and responsive interface
